# The Wider Edit

A private, noncommercial personal blog from Georgia, published under the pseudonym **Chris West**.

Separate Russian and German editions; Business, Leisure and Health. Forest green and paper white, responsive layouts, local graphics, system fonts. No advertising, paid services, forms, comments, advertising trackers or third-party embeds. GoatCounter counts pageviews without cookies; its script is the sole external script.

## Build

```sh
python3 build.py
python3 validate.py
```

The ready-to-publish site is in `docs/`. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/docs**, and save. After GitHub Pages builds successfully, the site is available at https://wideredit.github.io/the-wider-edit/.

Impressum is in German and Georgian; Datenschutz is in German. Hosting-related IP processing by GitHub is disclosed. The copyright-law reference concerns the author's right to use a pseudonym, not a blanket exemption from other legal requirements.

See [CONCEPT.md](CONCEPT.md) for launch boundaries and later editorial features. No fictional articles are published in this initial version.
