Datenschutz

Diese Website ist ein privater Blog. Sie verwendet keine Analyse- oder Werbedienste und bietet keine Registrierung, Kommentarfunktion oder Kontaktformulare an.

1. Technische Bereitstellung durch GitHub Pages

Der Blog wird über GitHub Pages bereitgestellt. Beim Besuch einer GitHub-Pages-Website wird die IP-Adresse des Besuchs laut GitHub aus Sicherheitsgründen protokolliert und gespeichert. Dies gilt auch ohne Anmeldung bei GitHub. Die Bereitstellung erfolgt somit nicht ohne technische Verarbeitung personenbezogener Daten.

Weitere Informationen über die Verarbeitung durch GitHub, die Speicherdauer, internationale Übermittlungen und die dort beschriebenen Datenschutzrechte finden Sie in den Informationen des Hostinganbieters:

  • GitHub Pages: Data collection ↗
  • GitHub General Privacy Statement ↗

Der Blog führt keine eigene Besucherdatenbank und verwendet keine eigenen Zugriffsprotokolle zur Auswertung des Besuchsverhaltens.

2. Keine Analyse, Werbung oder Profilbildung

Es werden keine Analyse-Pixel, Werbenetzwerke, Sitzungsaufzeichnungen oder Verfahren zur Erstellung von Nutzungsprofilen eingesetzt. Der Blog setzt keine eigenen Cookies und speichert keine Besuchsdaten im lokalen Browserspeicher.

3. Bilder, Schriften und Sprache

Die Website verwendet Systemschriften und lokal bereitgestellte Grafiken. Es sind keine externen Schriftendienste, Karten, Video-Player oder Social-Media-Widgets eingebettet.

Auf der Einstiegsseite wird die vom Browser bereitgestellte Sprache ausschließlich im Browser ausgewertet: Deutsch führt zur deutschen Ausgabe, andere Sprachen zur russischen Ausgabe. Es wird dafür kein Sprachprofil gespeichert und kein gesonderter Sprachdienst aufgerufen. Über RU und DE können Sie die Ausgabe wechseln.

4. Links zu anderen Websites

Externe Links werden erst aufgerufen, wenn Sie darauf klicken, und öffnen sich in einem neuen Tab. Auf der Zielseite gelten die Datenschutzinformationen des jeweiligen Anbieters. Der Blog erhält keine Vergütung für diese Links.

5. Änderungen

Diese Informationen beschreiben die gegenwärtige technische Gestaltung. Werden später weitere Funktionen eingeführt, werden die Hinweise entsprechend angepasst.
