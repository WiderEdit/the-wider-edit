Datenschutz

Diese Website ist ein privater Blog. Sie verwendet GoatCounter zur Zählung von Seitenaufrufen, aber keine Werbedienste. Es gibt keine Registrierung, Kommentarfunktion oder Kontaktformulare für Besucher.

1. Technische Bereitstellung durch GitHub Pages

Der Blog wird über GitHub Pages bereitgestellt. Beim Besuch einer GitHub-Pages-Website wird die IP-Adresse des Besuchs laut GitHub aus Sicherheitsgründen protokolliert und gespeichert. Dies gilt auch ohne Anmeldung bei GitHub. Die Bereitstellung erfolgt somit nicht ohne technische Verarbeitung personenbezogener Daten.

Weitere Informationen über die Verarbeitung durch GitHub, die Speicherdauer, internationale Übermittlungen und die dort beschriebenen Datenschutzrechte finden Sie in den Informationen des Hostinganbieters:

  • GitHub Pages: Data collection ↗
  • GitHub General Privacy Statement ↗

Neben dem Hosting durch GitHub wird der unten beschriebene Aufrufzähler von GoatCounter eingesetzt.

2. Seitenaufrufe mit GoatCounter

Um zu sehen, welche Beiträge gelesen werden, verwendet der Blog GoatCounter (Martin Tournoij, Irland). Beim Aufruf einer Inhaltsseite lädt der Browser das Zählskript von gc.zgo.at und sendet eine Anfrage an the-wider-edit.goatcounter.com. Übermittelt werden der Seitenpfad und der Seitentitel; URL-Parameter, Fragmente und die Herkunftsseite werden durch unsere Konfiguration nicht mitgesendet. Die technische Verbindung übermittelt außerdem die IP-Adresse und Browserinformationen an den Dienst.

Gezählt werden Seitenaufrufe, keine eindeutig identifizierten Personen. Die Sitzungszuordnung wird für diese Zählanfragen deaktiviert. Es werden keine Klickereignisse erfasst. Laut Anbieter speichert GoatCounter keine IP-Adressen dauerhaft und verwendet für die Besucherzählung keine Cookies oder Browserspeicher. Je nach Kontoeinstellungen können zusätzlich aggregierte technische Angaben wie Browser, Betriebssystem, Bildschirmgröße oder ungefähres Land erfasst werden. Es werden keine Werbeprofile erstellt.

Der Anbieter nennt Hetzner-Server in Deutschland und Finnland als Speicherorte. Weitere Informationen stehen in der Datenschutzerklärung von GoatCounter ↗. Die Statistik wird im Verwaltungsbereich des Dienstes betrachtet; auf diesem Blog ist kein öffentlicher Zähler eingeblendet. Browser mit aktiviertem Do Not Track oder Global Privacy Control werden durch unsere Integration nicht gezählt.

3. Bilder, Schriften und Sprache

Die Website verwendet Systemschriften und lokal bereitgestellte Grafiken. Es sind keine externen Schriftendienste, Karten, Video-Player oder Social-Media-Widgets eingebettet. Die externe Skriptverbindung für den Aufrufzähler ist unter Abschnitt 2 beschrieben.

Auf der Einstiegsseite wird die vom Browser bereitgestellte Sprache ausschließlich im Browser ausgewertet: Deutsch führt zur deutschen Ausgabe, andere Sprachen zur russischen Ausgabe. Es wird dafür kein Sprachprofil gespeichert und kein gesonderter Sprachdienst aufgerufen. Über RU und DE können Sie die Ausgabe wechseln.

4. Links zu anderen Websites

Externe Links werden erst aufgerufen, wenn Sie darauf klicken, und öffnen sich in einem neuen Tab. Auf der Zielseite gelten die Datenschutzinformationen des jeweiligen Anbieters. Der Blog erhält keine Vergütung für diese Links.

5. Änderungen

Diese Informationen beschreiben die gegenwärtige technische Gestaltung. Werden später weitere Funktionen eingeführt, werden die Hinweise entsprechend angepasst.
